## design-architecture

기획 산출물(비즈니스모델·유저스토리·이벤트스토밍)을 입력으로 AI 앱 아키텍처 설계서 7종
(목표/품질 카드 → 논리아키텍처 → 워크플로우 → 역할계약서 ⇄ 지식/도구 → 가드레일/관측 → 배포)과
반영대조표 1종을 정해진 순서로 생성한다.

**트리거 키워드**: "아키텍처 설계", "설계서 작성", "논리아키텍처", "워크플로우 설계", "역할계약서"

**사용법**
1. Claude Code에서 스킬을 호출하면 기획 산출물 디렉토리와 설계서 출력 디렉토리를 묻는다.
2. 기획 산출물(비즈니스모델·유저스토리·이벤트스토밍 문서)이 있는 절대경로를 입력한다.
3. 설계서 7종과 반영대조표가 지정한 출력 디렉토리에 순서대로 생성된다.

**입력 예시 위치**: `prompts/_shared/프로젝트정보.md`에 프로젝트 정보(V-01~V-12)를 먼저 채워야 함.

## develop-agentic-ai

아키텍처 설계서 7종을 입력으로 개발 프롬프트 9종(런타임·데이터셋·지식경로·커넥터·가드레일·워크플로우·
API/UI·배포·평가)을 정해진 순서로 호출해 실행 가능한 코드·시험·README를 생성한다.

**트리거 키워드**: "개발 시작", "코드 생성", "개발 프롬프트 실행", "설계서를 코드로"

**사용법**
1. `design-architecture` 스킬로 설계서 7종을 먼저 만들어 둔다(선행 조건).
2. 스킬을 호출하면 기획 산출물 경로, 설계서 경로, 프론트엔드 스택, 코드 루트 경로, 상태 저장 백엔드를 묻는다.
3. 답변 후 개발 프롬프트 9종이 순서대로(일부 병렬) 실행되어 코드 루트 경로 하위에 코드·시험·README가 생성된다.

**입력 예시 위치**: `prompts/_shared/개발환경정보.md`에 개발 환경 정보(D-01~D-12)가 채워짐(스킬이 대상 프로젝트에 인스턴스를 생성).

## prompt-enhancer

사용자가 제공한 프롬프트를 프롬프트 작성 가이드(구체성·업무배분·하네스 측면)에 따라 개선한다.

**트리거 키워드**: "프롬프트 개선", "프롬프트 수정"

**사용법**
1. 스킬을 호출하면 프롬프트 원문을 파일 경로로 줄지, 대화창에 직접 붙여넣을지 묻는다.
2. 구체성, 업무배분, 하네스 3가지 관점에서 병렬로 개선안을 만들고 Critic이 비판적으로 검토한다.
3. 최종 개선 결과가 `{프로젝트 디렉토리}/prompts/{file-name}_v{N}.txt`로 저장된다.

**참고 자료**: `references/prompt-guide.md`
